⚙️ Configuración de Firebase y Acceso QR Móvil

Si proyectás desde WAMP en una red Wi-Fi, el sistema detecta automáticamente la IP LAN local para que los celulares puedan escanear el QR directamente.
La presentación cuenta con sincronización híbrida en tiempo real: usa Firebase Realtime Database cuando ingresás tus credenciales, y además sincroniza instantáneamente mediante WAMP Server (sync.php) y BroadcastChannel sin requerir configuración previa.
